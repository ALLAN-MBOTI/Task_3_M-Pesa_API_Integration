# Task_3_M-Pesa_API_Integration
To Develop a REST API to handle C2B M-Pesa transaction callbacks and persist the data into a database.

---------------------------

Instructions
---------------------

Requirements:
    • The API should:
        ◦ Receive JSON payloads from M-Pesa transaction callbacks.
        ◦ Parse and extract all fields (e.g., TransactionId, TransAmount all fields.) into separate string fields.
        ◦ Save all parsed transaction details into the database.
    • The API should return a structured JSON response confirming successful data capture.
